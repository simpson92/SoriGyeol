영역별 설명

1데이터비중 큼
모델이 배울 재료를 모으고, 공정하게 평가할 수 있게 정리한다.
  • 1차 클래스 사이렌·경적·배경 (경보음은 꺼 둠, 초인종/노크는 후보)
  • 같은 원본 녹음이 학습·평가에 섞이지 않게 분할 (겹침 0개 확인)
  • 클래스 목록은 classes.yaml 하나로 관리 → 웹용 classes.json으로 내보냄
도구 pandas · librosa · AI Hub (WSL로 다운로드)
2AI 모델링가장 큼
기준 → 작은 분류기 → 자체 CNN을 같은 한국 테스트셋에서 숫자로 비교한다.
  • Baseline 대비 개선을 증명 — 해외만/한국만/혼합 비교
  • 위험 소리 재현율 · 시간당 오알림 · 소음(SNR)별 성능이 핵심 지표
  • 평가로 클래스별 기준 점수와 점수→확률 변환표를 만들어 웹에 전달
도구 MediaPipe · scikit-learn · PyTorch · SpecAugment · ONNX(CNN 비교 시)
3오디오 신호처리비중 중간
끊김 없이 들어오는 소리를 실시간으로 잘라 모델에 넣고, 결과를 안정화한다.
  • 1초 창을 0.5초마다 분류, 3구간 중 2구간 감지 시에만 알림해 오알림 감소
  • 가까워짐/멀어짐: 소리 크기 기울기 (+1.5dB/초 2회 / −3dB/초 3회)
  • 방향: 두 채널 크기 차·도착 시간차로 좌/우 실험, 한계는 표로 정리
도구 Web Audio API (AudioWorklet) · NumPy/SciPy (분석)
4프론트엔드비중 중간
감지 결과를 사용자가 느끼고 볼 수 있게 만드는 화면과 진동.
  • 폰 마이크 입력 + 브라우저 안 YAMNet 실행 + 진동 API + 화면 깜빡임
  • 한 화면에 지금 소리 · 확률 · 소리 크기, 개발 정보는 접어 둠
  • manifest · 서비스 워커로 홈 화면 설치 지원 (예정)
도구 HTML/CSS/JS · MediaPipe Tasks Audio · Wake Lock API
5UX/디자인비중 중간
"걸으면서 화면을 보지 않아도 알 수 있게" — 안전 중심 설계 원칙.
  • 이동 중 진동 우선, 정지 시 화면 상세 확인
  • 진동 패턴은 처음엔 긴급·일반 2종으로 단순하게
  • 깜빡임은 초당 2회 이하(광과민 안전), 색 대비·색각 이상 고려
산출물 화면 시안 · 진동 패턴 표 · 알림 우선순위 규칙
6배포·협업비중 작음
코드를 버전 관리하고, 누구나 실행·접속할 수 있게 한다.
  • 짧은 브랜치 + PR, docs는 main에 바로 (git-workflow.md)
  • 원본 데이터는 올리지 않고 받는 방법만 기록, uv 가상환경
  • main에 합쳐지면 GitHub Actions가 Pages로 자동 배포
도구 Git · GitHub · GitHub Actions · GitHub Pages · uv
